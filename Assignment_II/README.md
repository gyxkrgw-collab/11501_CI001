# Assignment II — Archive Your Code

Archive of all code developed in C++ Programming Laboratory (I) this semester: on-site examinations (UVa Online Judge), before-class exercises (LeetCode), and after-class practices (LeetCode).

Each problem folder contains a `README.md` written from the [README template](./README_template.md) and a `src` directory with the source code.

## Folder Structure

```
Assignment_II
├── On-Site_Examinations      # UVa on-site problems (regular: required, bonus: bonus)
├── Before-Class_Exercises    # LeetCode before-class exercises (bonus)
├── After-Class_Practices     # LeetCode after-class practices (bonus)
├── README_template.md
└── README.md
```
